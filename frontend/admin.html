Admin Help - JSON Syntax
Bulk Add Users (JSON Array)

Use this format in the Bulk Add text area:

[
  {
    "username": "user1",
    "password": "password123",
    "fullName": "User One",
    "role": "ROLE_USER" (optional)
  },
  {
    "username": "admin1",
    "password": "securepass",
    "role": "ROLE_ADMIN"
  }
]

Note: Duplicate usernames will be skipped.
